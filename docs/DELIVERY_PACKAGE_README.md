# V2 author-review package

The active core contains90 complete RTX4060 model executions and486 frozen-feature fits, for576 conditions/runs in the fixed identity matrix. The72 completed CPU reference runs and27 equal-available-pixel supplemental runs are separate evidence; the same90 GPU executions are not counted twice. The18 remaining CPU executions were replaced by their already completed GPU identities at the user's request. This resource-directed amendment occurred after panel exposure; the active main display is descriptive and is not a newly prospective confirmatory test. See configs/v2_active_gpu_amendment.json.

Start with paper/v2/manuscript.pdf and paper/v2/supplementary_material.pdf; editable Word files and JSON sources are alongside. Use python -B code/v2_active_gpu_results.py --verify-tables to check the six numerical files without refitting. The original CPU reference checkpoint has a separate72-image reload check; it is not an archived GPU checkpoint. Data, exact192 frozen-feature caches, active results and CPU reference evidence preserve their original relative paths and hashes.

This is an AUTHOR_REVIEW_PACKAGE. Author identities, affiliations, funding, declarations and final human approval remain to be completed. No submission, publication, payment or public data upload has been performed. Source attribution and unresolved dataset rights are documented in docs.

delivery_manifest.json covers every delivered file except itself. The source write-ahead ledger and migration receipt preserve the original locations.
