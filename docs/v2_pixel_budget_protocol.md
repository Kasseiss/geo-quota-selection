This is a post-panel-exposure supplemental experiment. The original576-fit study and its primary contrast remain unchanged. The additional90-fit CUDA execution replication also remains unchanged. No claim of a fresh confirmatory holdout, public preregistration, equivalence, annotation-time savings or a new selection algorithm follows from this addition.

## Rationale and fixed scope

The reviewer-style concern is that equal image counts need not mean equal available labeled pixels. The existing source-only diagnostic covers all90 planned complete-model selections at the processed448 grid. Its minimum valid-label count is2,303,273 and its maximum is2,408,419, out of2,408,448 total pixels in12 images. These are source-mask quantities measured after selection, not target performance. A common budget of2,300,000 available valid pixels is below every selected subset's observed availability and requires no image or fit exclusion. This budget is chosen from source availability, rather than an effect-size search or target score.

Use the exact ordered selections from `configs/v2_cuda_execution_plan.json` for all three source allocations, paired seeds0/1/2 and the three strategies `kcenter`, `region_kcenter`, and `permuted_region_kcenter`:27 fits. Hold the complete ResNet18/U-Net-style model, pretrained weights, source-selected learning rates and step counts, batch2, crop224, augmentation, cross entropy, optimizer, fitting seed, runtime and72-image evaluation panel fixed to the recorded CUDA recipe. Selection receives no mask or class-count information. Existing source-validation20 images per allocation remain unchanged.

## Available-label intervention

For each selected12-image subset, enumerate original nonvoid processed pixels in the plan's ordered selected-image sequence, and within each image in row-major order. With a separate NumPy generator seeded by `2026101811 + selection_seed`, choose uniformly without replacement exactly `original_valid_count - 2300000` positions to hide. Set only those training targets to the existing ignore index255. Original void pixels remain ignored. Do not use classes, regional scores, validation performance or panel labels to choose the hidden positions. Do not change RGB images, the selected image sequence, original mask files or target masks.

The resulting available supervision set has exactly2,300,000 unique valid pixels per fit. Record each image's original and retained valid counts, eight retained class counts, retained-mask hash, the combined count and the independent mask seed. Retain the same masked supervision set throughout that fit. The model's crop sampling and augmentation retain their original optimization RNG; the mask generator must not consume that RNG stream. In particular, the original16-attempt crop-validity rule must continue to inspect complete original source masks, so thinning cannot change crop eligibility, retry counts or subsequent augmentation draws. If a crop selected under that original rule contains no retained supervision pixels, stop and retain the failure evidence; do not draw again or add supervision. Model fitting sees masked source targets, while source validation and panel evaluation use original complete masks. Any temporary training-loader and batch-sampler wrappers must be restored before evaluation, including on failure.

This control equalizes the number of available unique processed supervision pixels. It does not equalize native annotation area, human labeling time, semantic information, realized cumulative nonvoid crop visits, class distributions or ground footprint. Resampling and repeated crop use are therefore reported as remaining distinctions. It does not retrospectively make the original experiment pixel-matched.
